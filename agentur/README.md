# Agentur – KI-gestütztes Kleingewerbe

Der Inhaber entscheidet und haftet, die Claude-Agenten arbeiten zu.
**Hinweis:** Dieses Repo ist öffentlich. Persönliches gehört nicht hier hinein; das Projekt zieht in ein privates Repo um.

| Datei | Inhalt |
|---|---|
| `VERFASSUNG.md` | Grundregel (unveränderlich), Zielrangfolge, Freigabepflicht |
| `FINANZREGELN.md` / `config.json` | Steuer-Rücklage, gestaffelte Gewinnaufteilung, Verlustgrenzen |
| `AGENTEN.md` / `zeitplan.json` | Agenten-IDs, Rollen, Aktivitätszeiten, Nutzungsbudget |
| `SICHERHEIT.md` | Privates Repo, Verschlüsselung sensibler Dateien |
| `STARTPLAN.md` | Phasen bis 5.000–6.000 € brutto/Monat und darüber hinaus |
| `STATUS.md` | aktueller Stand, offene Aufgaben, wartende Freigaben |
| `ledger.csv` + `rechner.py` | Buchführung und Wirtschaftsrechner (monatlich) |
| `journal/` | ein Eintrag pro Arbeitssitzung |
